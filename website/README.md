# SyncNode Website & Promotional Content

This folder contains the promotional site content, product story, and marketing documentation for SyncNode.

## Contents

| File | Description |
|---|---|
| [`idea.md`](idea.md) | The original product vision — why SyncNode exists |
| [`features.md`](features.md) | Feature breakdown for the product site |
| [`roadmap.md`](roadmap.md) | Public roadmap and release milestones |
| [`use_cases.md`](use_cases.md) | Real-world use cases and demo scenarios |
| [`faq.md`](faq.md) | Frequently asked questions |
| [`press.md`](press.md) | Press kit, taglines, and brand notes |

## Purpose

These documents are the source of truth for:
- The public-facing product website
- Demo scripts and sales materials
- Community documentation
- Release announcements

## Building the site

This content is designed to be consumed by a static site generator (Astro, Next.js, or similar). Each `.md` file maps to a page on the promotional site.
